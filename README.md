# E-Commerce Customer & Sales Analytics

## Project Overview

This project analyzes the Brazilian E-Commerce Public Dataset by Olist to understand sales performance, customer behavior, product categories, and delivery performance.

The goal is to transform raw e-commerce data into meaningful business insights using data analysis and visualization tools.

## Objectives

* Analyze sales and order performance.
* Understand customer purchasing behavior.
* Identify top-performing product categories.
* Evaluate order delivery performance.
* Perform data cleaning and data quality checks.
* Develop business insights to support data-driven decisions.

## Tools & Technologies

* **SQL:** PostgreSQL
* **Python:** Pandas, NumPy
* **Data Visualization:** Tableau, Power BI
* **Database Management:** pgAdmin
* **Dataset:** Brazilian E-Commerce Public Dataset by Olist

## Project Workflow

1. Data collection and understanding
2. Data cleaning and quality validation
3. Database setup and SQL analysis
4. Exploratory data analysis using Python
5. KPI development and business analysis
6. Dashboard development
7. Business insights and recommendations

## Key Areas of Analysis

* Sales and revenue trends
* Product category performance
* Customer purchasing patterns
* Order and delivery performance
* Payment behavior
* Customer review analysis

## Dataset

The project uses the Brazilian E-Commerce Public Dataset by Olist, available on Kaggle.

Dataset source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
